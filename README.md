# dev-radar

Mod pentru Claude Code: panou lateral „Radar” (subagenți, fișiere editate, tokeni), bandă cu context/cost și avertizări utile în dezvoltare.

## Instalare (în orice sesiune, scope user)

```
/plugin install dev-radar --marketplace andreicreteanu06-design/cafea
```

Pe sesiuni care rulează în acest repo se activează automat din `.claude/settings.json`.
